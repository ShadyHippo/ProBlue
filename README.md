# ProBlue

Linux support for **Nintendo Switch Pro Controller cable pairing**: plug the
controller in over USB-C, let it pair over the wire, unplug, and use it as a
normal Bluetooth controller.

The project lives in [`V2/`](V2/README.md) — **start there**:

- [`V2/README.md`](V2/README.md) — what it is, why, how it works, and why each
  piece of code is needed
- [`V2/src/`](V2/src/README.md) — the full patched files and the patches
- [`V2/docs/KEY_CONTEXT.md`](V2/docs/KEY_CONTEXT.md) — protocol digest
- [`V2/docs/hardware/`](V2/docs/hardware/) — an unrelated host-radio quirk on the
  author's machine (secondary)

`V1/` is a **frozen reference archive** of an earlier attempt. It is kept for
provenance only and is not maintained.
